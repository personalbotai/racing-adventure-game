# Racing Adventure 3D

Game balap mobil 3D sederhana menggunakan Three.js.

## Fitur
- Kontrol dengan WASD atau Arrow Keys
- Kumpulkan koin untuk skor
- Lingkungan 3D dengan pohon dan trek
- Timer dan skor

## Cara Menjalankan
1. Install dependencies: `npm install`
2. Jalankan development server: `npm run dev`
3. Build untuk produksi: `npm run build`

## Deploy ke GitHub Pages
1. Buat repositori baru di GitHub
2. Tambahkan remote origin: `git remote add origin https://github.com/[username]/[repo-name].git`
3. Push ke master: `git push -u origin master`
4. Deploy: `npm run deploy`
